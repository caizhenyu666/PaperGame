# 正式关卡 HUD 实现计划

> **面向 AI 代理的工作者：** 在当前任务中内联执行；每项按红灯、最小实现、绿灯顺序完成。

**目标：** 用正式纸张主题预制体替换临时关卡 HUD，并实现页码与暂停确认流程。

**架构：** `C1GameHudController` 负责预制体绑定和运行时行为；`C1GameBootstrap` 仅实例化并配置它。`C1GameSession` 提供跨场景页码；编辑器生成器从约束 Schema 生成预制体。

**技术栈：** Unity 2022.3、UGUI、NUnit EditMode、Resources。
