# 正式关卡 HUD 设计

## 目标

将运行时临时拼装的关卡 HUD 替换成可复用的 `PaperGameGameHUD` 预制体。保留关卡世界和黄色纸张背景，并让所有内置、服务器生成关卡共用正式按钮与暂停流程。

## 布局

基准画布为 1920×1080，使用 `Scale With Screen Size` 和 0.5 宽高匹配。左上纸条显示“第 N 页”；右上为暂停按钮；左下为独立的左、右移动按钮；右下为跳跃按钮。所有控件锚定四角并保留安全边距，不烘焙进关卡背景。

## 暂停流程

点击暂停后将 `Time.timeScale` 设为 0，清空移动按压状态并显示模态遮罩。弹窗提供“返回主界面”和“继续游戏”：返回会恢复时间后调用既有 `ReturnHome`；继续会关闭弹窗并恢复进入弹窗前的时间倍率。组件禁用或销毁时也恢复时间，避免场景切换后仍暂停。

## 页码

`C1GameSession` 保存当前页码，默认关卡为第 1 页。关卡列表播放时按当前显示顺序写入从 1 开始的页码，自建关卡进入游戏后显示对应编号。

## 资源与生成

已有左右箭头、跳跃和返回首页切图复制至 `Assets/Resources/C1GameUI`，保持透明 PNG。由于原资源目录没有独立暂停切图，使用内置 imagegen 并引用正式关卡截图生成同风格的独立透明资源，提示词要求只保留圆形撕纸按钮、蓝色蜡笔双竖线、透明背景、无其他 UI；生成后按明确规格缩放为 256×256。Schema 存放于 `Assets/Editor/AIUI/Schemas/C1GameHUD.ui.json`；Unity 编辑器生成器读取固定节点约束并生成新的业务预制体，不手改 YAML，也不覆盖首页或角色预制体。

## 验证

Editor 测试验证预制体结构、锚点、按钮资源、动态页码、暂停/继续/返回行为以及原有移动和跳跃输入。使用隔离 Unity 工程生成预制体并运行完整 EditMode 回归。
