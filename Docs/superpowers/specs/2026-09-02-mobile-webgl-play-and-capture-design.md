# 手机 WebGL 游玩与拍照合并设计

## 目标与范围

让当前 PaperGame WebGL 在手机浏览器中形成两个可验收闭环：

1. 横屏触控游玩：按住左右移动，点击跳跃。
2. 调起手机系统相机：拍照后将原始 JPEG/PNG 返回 Unity，并显示预览。

本阶段不包含图片上传、OpenCV 处理、动态生成关卡、作品分享、账号、云存储或原生 APK/IPA。

## 总体结构

两个功能共用现有 `C1 HUD` 和 EventSystem：

- 左下角：半透明左、右按钮。
- 右下角：半透明跳跃按钮。
- 上方：拍摄关卡按钮和状态文字。
- 中央预览层：成功拍照后显示原始比例缩略预览，可关闭或再次拍摄替换。
- 竖屏遮罩：触屏设备竖屏时提示旋转手机，横屏后自动隐藏。

Unity 默认 WebGL 移动模板已经提供 viewport 和全屏 Canvas，本次继续使用该能力。所有 HUD 控件采用 `Scale With Screen Size` 与屏幕锚点，不修改照片背景、相机或关卡像素坐标。

## 触控游玩

### 输入模型

- `C1PlayerController2D` 新增触控水平输入状态。
- 每帧合并键盘与触控：键盘当前有方向输入时使用键盘，否则使用触控方向。
- 左右按钮支持 PointerDown、PointerUp、PointerExit；按住持续移动，松手或移出立即停止。
- 左右同时按住时方向抵消；松开其中一个后恢复另一个方向。
- 跳跃按钮在 PointerDown 时调用现有 `TryJump()`，继续遵守落地检测和禁止二段跳规则。
- 角色完成、掉落或控件禁用后清除触控输入。

### 显示规则

- 触控按钮仅在移动/触屏环境显示。
- EditMode 测试可直接构造组件并调用输入方法，不依赖真实触屏设备。
- 桌面端原有 `A/D`、方向键和空格保持不变。

## 手机拍照

### 浏览器桥接

WebGL `.jslib` 插件在用户点击“拍摄关卡”时创建隐藏控件：

```html
<input type="file" accept="image/jpeg,image/png" capture="environment">
```

浏览器使用 `FileReader.readAsDataURL` 读取照片，再通过 `SendMessage` 返回 Unity。Base64 仅作为传输表示，不重新编码、不缩放、不压缩；Unity 解码后保存原始字节，并通过 `Texture2D.LoadImage` 生成内存预览。

拍照调用必须直接来自用户点击，不能在页面加载时自动申请相机权限。

### 数据规则

- 仅接受 JPEG、PNG，单张最大 15 MiB。
- 保留最近一次成功图片的原始字节和 `Texture2D`，供后续上传接口复用。
- 再次拍照成功后释放旧预览纹理并替换；失败或取消不覆盖旧照片。
- EXIF 方向、透视、裁切、压缩和图像识别本阶段均不处理。
- 页面刷新后内存照片消失，不做持久化。

### 状态与错误

- 等待选择：`请选择拍摄关卡照片`。
- 读取中：`正在读取照片…`。
- 成功：`照片已获取`。
- 类型错误：`请拍摄或选择 JPEG/PNG 图片`。
- 超限：`照片过大，请重新拍摄`。
- 解码失败：`照片读取失败，请重试`。
- Unity Editor 中点击：`请在 WebGL 或手机浏览器中拍照`。

## 组件边界

- `C1PlayerController2D`：合并键盘与触控输入。
- `C1MobileControls`：维护左右按压状态与跳跃转发。
- `C1TouchDirectionButton`、`C1TouchJumpButton`：处理 Pointer 事件。
- `C1PhotoCapture`：调用浏览器、校验返回值、保存原始字节、管理预览纹理。
- `PaperGamePhotoCapture.jslib`：封装浏览器文件拍摄与 Data URL 回传。
- `C1MobileOrientationHint`：根据触屏环境和宽高判断旋转提示。
- `C1GameBootstrap`：只负责创建和装配 HUD 控件。

## 测试与验收

### 自动测试

- 触控左、右、同时按下、释放与禁用后的输入状态正确。
- 触控输入不会破坏键盘输入路径。
- 跳跃按钮复用已有落地和二段跳限制。
- 有效 PNG/JPEG 可保留原始字节并生成正确尺寸预览。
- 类型错误、超过 15 MiB、解码失败不会覆盖旧照片。
- 再次拍照释放并替换旧纹理。
- Bootstrap 创建完整移动 HUD，照片背景与不可见碰撞测试继续通过。

### WebGL 验收

- 构建成功，浏览器控制台无新增运行错误。
- 手机横屏时按钮位置可触达且不遮挡主要关卡区域。
- 按住左右可持续移动，松手停止；跳跃可用。
- 点击拍摄按钮后由系统打开后置相机/图片选择界面。
- 确认照片后 Unity 显示预览和成功状态。
- 竖屏显示旋转提示，横屏恢复游戏界面。

## 后续接口预留
