# 角色生成 Loading 设计

## 目标

角色照片上传、服务器生成和动画图集下载期间，显示与现有记事本主题一致的全屏 Loading，持续反馈当前阶段，并允许用户取消。取消后彻底丢弃本次生成任务，用户需要重新拍照才能再次生成。

## 视觉设计

- 设计基准为 1920×1080、16:9，沿用角色创建界面的 Canvas Scaler 与适配规则。
- Loading 作为角色创建界面的最上层全屏遮罩，使用半透明暖米黄色覆盖，保留背景轮廓但阻止所有底层交互。
- 中央放置一张透明背景的蜡笔风格插画：绿色独眼角色与黄色小鸡围着一张正在绘制的小纸片。角色外形必须与项目默认角色一致。
- 插画不包含文字，避免生成图中文字失真；运行时以轻微上下浮动和呼吸缩放表示持续进行。
- 插画下方使用 Unity 文本显示当前状态，例如「正在上传照片…」「小主角正在排队，请稍等…」「正在让你的涂鸦动起来…」「正在下载角色动画…」。
- 当前状态下方增加一行趣味提示，每约 2.5 秒随机无重复轮播，例如「正在给小主角穿上跑鞋…」「给它画一个勇敢的表情…」「正在练习跳得更高…」「彩色蜡笔正在努力工作…」「马上就能见到新朋友啦…」。趣味提示不替代真实阶段状态。
- 底部使用红色撕纸风格按钮，按钮图片包含准确文字「取消生成」，保持与现有纸张按钮一致的手绘轮廓、阴影和蜡笔质感。

## 资源

- `Assets/Resources/C1CharacterUI/loading-character.png`：透明背景 Loading 插画。
- `Assets/Resources/C1CharacterUI/cancel-generation.png`：透明背景取消按钮，包含「取消生成」文字。
- 两张图片均作为单图 Sprite 导入，关闭 Mipmap，启用透明通道，不压缩。
- 使用内置图像生成工具，以项目现有绿色独眼角色和黄色小鸡图片作为角色参考；生成后复制到项目目录，不依赖临时路径。

## 预制体结构

在 `PaperGameCharacterSelection` 中新增根节点 `Generation Loading`，默认隐藏，并包含：

- `Blocker`：全屏半透明 Image，接收 Raycast，阻断底层交互。
- `Loading Art`：中央插画 Image，保持宽高比。
- `Loading Status`：动态状态 Text。
- `Loading Tip`：随机轮播趣味文案 Text。
- `Cancel Generation`：带正式切图的 Button。

预制体继续由 `PaperGameCharacterPrefabGenerator` 和 `C1CharacterScreenLayout` 生成，不直接编辑 Prefab YAML。运行时兜底布局与生成预制体保持一致。

## 状态与数据流

- 拍照成功后，在开始上传前显示 Loading。
- 上传、轮询和下载动画图集期间保持 Loading 可见，并将服务端进度文字同步到 `Loading Status`。
- 生成成功且角色动画完成下载、缓存和列表刷新后关闭 Loading。
- 上传失败、生成失败、数据无效或下载失败时关闭 Loading，并把错误显示在原有状态区域。
- 浏览已有远程角色时沿用 Loading，但取消只停止当前下载，不删除已经保存的角色记录。

## 取消行为

生成流程中点击「取消生成」后：

1. 停止当前上传、轮询或下载协程，并释放正在执行的 `UnityWebRequest`。
2. 清空 `library.pendingJobId` 并保存角色库。
3. 清空当前照片字节、照片 MIME、强制重试与下载重试状态。
4. 隐藏 Loading，解除底层界面锁定。
5. 显示「已取消生成，请重新拍照创建角色」。

取消不会调用服务端删除接口；服务端可能继续计算，但客户端永久丢弃该任务编号，不再恢复或查询结果。

## 动画与交互

- 动画使用 `Time.unscaledDeltaTime`，不受游戏时间缩放影响。
- Loading 插画上下浮动幅度不超过 12 px，呼吸缩放范围为 0.97–1.03，同时在 ±2° 范围内缓慢左右摇摆，避免儿童界面出现眩晕感。
- 趣味文案使用独立随机序列，连续两次不得显示相同内容；每次打开 Loading 时立即显示一条。
- 取消按钮在执行取消后立即禁用，防止连续点击。
- 页面返回、对象销毁或角色创建界面关闭时，停止未完成操作并恢复 UI 状态。

## 测试

- 验证生成预制体包含 `Generation Loading`、`Loading Art`、`Loading Status`、`Loading Tip` 和 `Cancel Generation`，且遮罩默认隐藏。
- 验证开始生成时遮罩显示，底层按钮不可交互。
- 验证进度回调会更新 Loading 文本。
- 验证趣味文案按不受时间缩放影响的计时轮播，且连续两次不重复。
- 验证取消后停止操作、清空任务编号和照片状态、隐藏遮罩，并恢复界面交互。
- 验证生成成功和失败都会关闭遮罩。
- 验证 1920×1080、方屏和超宽屏下遮罩覆盖完整画面，中央内容保持设计比例。

## 非目标

- 不新增服务端取消或删除任务接口。
- 不展示虚假的百分比进度；服务端仅提供阶段状态时只展示阶段文案。
- 不修改角色生成算法、动画图集格式或角色尺寸规范。
