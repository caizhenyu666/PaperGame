# 纸上游戏 UI 正式视觉与切图设计

## 目标

为现有《换个星 JO》首页补齐 2 个正式横屏页面：游戏内关卡 HUD 与「创建主角」页。视觉必须延续已确认首页：米白颗粒纸、黑色铅笔轮廓、儿童蜡笔涂色、撕纸标题与手写涂鸦；不使用通用手机 App 的扁平组件。

本轮交付包括 Figma 页面稿、可导入 Unity 的 PNG 切图与导入约定。文本和动态状态不烘焙进位图，避免 AI 生成错误中文并支持运行时本地化。

## 画面规范

| 项目 | 约定 |
| --- | --- |
| 基准尺寸 | 1920 × 1080，手机横屏 16:9 |
| 背景 | 暖白纸纹底；细微纤维颗粒；不使用规整蓝色横线 |
| 描边 | 深灰黑色铅笔线，边缘存在轻微抖动与粗细变化 |
| 主操作 | 橙黄色蜡笔涂色按钮，白色粗描边字，深色铅笔外轮廓 |
| 次操作 | 草绿色蜡笔涂色按钮，保持首页的圆润比例 |
| 信息容器 | 撕边白纸、浅灰投影、左侧 4 个活页孔；容器仅承载信息，不做大面积遮罩 |
| 标题 | 白色撕纸底 + 红、蓝、绿、橙蜡笔字；页面内标题以深灰手写体为主 |
| 装饰 | 蓝色涂鸦云、太阳、草丛、花朵、红旗与铅笔箭头；边缘装饰不得遮住触控区 |

## 页面一：关卡 HUD

### 布局

- 中央约 70% 保持关卡原始纸张、平台线与角色画面，HUD 不添加不透明全屏底。
- 左上为「第 1 页」撕纸角标；内部可放关卡名称与 3 颗手绘星星，不显示分数、商城或复杂任务。
- 右上为 96 × 96 参考像素的圆形暂停按钮：铅笔描边、白纸底、两根蓝色蜡笔竖线。
- 左下为并列的左右移动按键：白纸方形、蓝色蜡笔箭头、压下态为浅蓝涂色。
- 右下为黄色圆形「跳」键，带铅笔放射线；它是唯一的高饱和动作按钮。
- 完成或失败使用居中的撕纸结果卡：成功配红旗、彩纸、星星；重试配铅笔箭头与「再试一次吧」。

### 交互状态

- 默认、按下、禁用 3 个状态均采用同一切图底，Unity 仅切换色调与缩放。
- 触控按钮最小 96 × 96 参考像素，按钮间距至少 24 参考像素。
- 竖屏旋转提示沿用现有流程，不生成新控制逻辑。

## 页面二：创建主角

### 布局

- 顶部使用撕纸标题「我的小主角」，右上为铅笔画的返回箭头与「回到首页」。
- 左栏是带活页孔的「角色小本本」：默认主角与用户涂鸦各占一个可点击纸条；选中项贴一张黄色星星贴纸。
- 中央为大号白纸预览台，底部画有一条铅笔地面线；显示当前角色的跑步或跳跃动画。
- 右栏放两张可切换的便签：「跑一跑」和「跳一跳」。
- 左下放草绿色次按钮「拍照做主角」；相机权限、上传、生成中与失败提示显示为一张小撕纸便签。
- 右下放橙黄色主按钮「用这个主角闯关」，未完成生成时置灰。

### 文本与异常

- 文本由 Unity `Text`/TMP 渲染；切图中只保留无字底图、图标和装饰。
- 生成中显示铅笔旋转圈与「正在把涂鸦变成主角…」；失败显示带回形针的提示纸与可重试按钮。
- 没有角色记录时仍保留默认主角，可直接进入关卡。

## Figma 组织

- 页面 `00 · Foundations`：色板、描边、纸张、字体样式与间距 token。
- 页面 `01 · 关卡 HUD`：默认、按下、暂停、成功、重试 5 个 Frame。
- 页面 `02 · 创建主角`：默认、角色选中、生成中、生成失败 4 个 Frame。
- 页面 `03 · Export`：只放可导出的无字 PNG；每个资源标注文件名、尺寸和 Unity 导入类型。

## 验收标准

1. 两页在 1920 × 1080 与窄横屏下均不遮挡玩法区和触控区。
2. 任意切图在 Unity 中与首页并排时，纸张色、铅笔线和蜡笔饱和度一致。
3. 所有按钮、容器可采用九宫格拉伸，不出现文字或装饰边缘被拉伸变形。
4. AI 仅生成无文字资产；所有中文文案可在 Unity 中单独修改。
5. 每个导出资源有明确文件名、像素尺寸、透明底与导入说明。
