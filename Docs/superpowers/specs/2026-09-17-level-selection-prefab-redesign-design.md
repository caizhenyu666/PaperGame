# 关卡选择界面预制体重设计

## 背景与目标

当前关卡选择界面由 `C1LevelSelection` 在运行时创建基础 `Image`、`Text` 和 `Button`。页面仍是测试样式，与首页、角色选择页和游戏 HUD 的绘本手账风格不一致，也不利于在 Unity Editor 中检查和调整布局。

本次改造需要达到以下目标：

- 新增独立的关卡选择界面 Prefab，替代整页运行时拼装。
- 视觉风格与现有「我的小主角」界面保持一致。
- 保留关卡浏览、预览、开始游戏、拍照创建、绘画帮助和返回首页能力。
- 将原有「继续生成」和「重新上传」收敛为一个按条件显示的「重新生成」入口。
- 首页只保留「开始游戏」入口；拍照创建移动到关卡选择页内。
- 不修改关卡解析、相机、存储和游戏加载协议。

## 方案选择

采用「手账双栏」布局。

- 左侧使用手账式纵向列表，展示内置关卡、本地关卡和「拍照创建新关卡」入口。
- 右侧使用大尺寸纸张区域展示当前关卡预览。
- 顶部放置撕纸标题、「怎么画？」和「返回首页」。
- 底部放置状态说明、按条件显示的「重新生成」和黄色主按钮「开始关卡」。

未采用的方案如下：

- 「大画幅胶片」：预览面积最大，但底部横向列表不利于展示较长的关卡标题和生成状态。
- 「关卡卡片墙」：可同时看到更多关卡，但近方形屏幕下容易拥挤，视觉结构也与现有角色选择页差异较大。

手账双栏与角色选择页的结构最接近，用户能直接复用已有的视觉和操作认知。

## 视觉设计

- 设计基准为横屏 `1920×1080`、16:9，沿用现有 `CanvasScaler` 和安全区适配规则。
- 背景使用米白色纸张纹理，搭配蓝色云朵、黄色太阳、绿色草地和树木等蜡笔装饰。
- 标题使用不规则撕纸底板和手写风格中文字体，文案为「我的纸上关卡」。
- 左侧关卡册复用手账纸张、装订孔、星标和黄色蜡笔选中框。
- 右侧预览复用大张纸片和胶带装饰。运行时关卡图片位于纸片内部，不遮挡纸张边缘。
- 主操作使用黄色蜡笔按钮，辅助或恢复操作使用绿色蜡笔按钮。
- 正式界面不使用 Emoji、系统图标或通用扁平卡片。图标与装饰只复用项目中已有的同风格 Sprite；缺少素材时登记为待补资源，不臆造路径。

## 页面结构

主预制体路径为：

`Assets/Resources/C1UI/PaperGameLevelSelection.prefab`

建议的节点结构如下：

```text
PaperGameLevelSelection
├── Background
├── Decorations
│   ├── Cloud Left
│   ├── Sun
│   ├── Cloud Right
│   ├── Tree Left
│   ├── Tree Right
│   └── Bottom Grass
├── Title
├── Drawing Help
├── Back Home
├── Level Book
│   ├── Viewport
│   │   └── Content
│   │       └── Level Item Template
│   └── Create Level
├── Preview Paper
│   └── Level Preview
├── Status
├── Regenerate
└── Play
```

`Level Item Template` 默认隐藏，运行时按关卡数量复制。条目包含缩略图、标题、来源说明、星标和选中框。只有业务代码需要访问的节点才建立序列化绑定。

## Prefab 生成方式

- 新增 `Assets/Editor/AIUI/Schemas/C1LevelSelection.ui.json`，记录 `1920×1080` 画布、节点层级、组件类型和正尺寸。
- Schema 只使用项目现有 AI UI Schema 已出现的纸张组件，例如 `PaperPanel`、`PaperImage`、`PaperText`、`PaperImageButton`、`PaperTextButton` 和 `PaperLabel`。
- 新增 `PaperGameLevelSelectionPrefabGenerator`，遵循现有首页、角色选择页和 HUD 的 Editor 生成器模式，完成精确布局与 Sprite 绑定。
- 正式 Prefab 通过 Unity Editor 生成器创建，不直接编辑 `.prefab` YAML。Schema 同时作为受约束的结构描述和校验输入。
- 不覆盖 `PaperGameHome`、`PaperGameCharacterSelection` 等共享 Prefab，也不修改共享 Sprite 内容。

## 组件边界

### `C1LevelSelection`

保留现有业务职责：读取关卡库、选择关卡、生成关卡、显示进度、打开绘画引导、打开相机和进入游戏。

改造后不再创建整页 UI。组件从 Prefab 获取节点引用，并负责：

- 使用条目模板刷新关卡列表；
- 更新选中框、星标、缩略图、预览图和状态文案；
- 根据状态控制「重新生成」的显隐与可交互状态；
- 在繁忙状态锁定列表和按钮；
- 在销毁时释放运行时纹理并解绑相机事件。

### `C1LevelSelectionLayout`

集中描述 `1920×1080` 基准布局、Sprite 绑定和节点创建逻辑，供 Editor 生成器使用。该类不读取关卡数据，也不处理业务事件。

### `HomeBootstrap`

- 从 `Resources/C1UI/PaperGameLevelSelection` 实例化关卡选择 Prefab。
- 取得 `C1LevelSelection` 并调用 `Configure`，不再调用 `C1LevelSelection.Panel` 创建根节点。
- 首页「开始游戏」进入关卡选择页。
- 首页隐藏原「拍照生成关卡」按钮；拍照创建统一从关卡选择页发起。

## 状态与交互

### 默认与选择状态

- 页面打开时默认选中内置「第 1 页」。
- 选中条目使用黄色蜡笔边框和实心星标，其余条目使用普通纸张和空心星标。
- 点击条目后更新预览图、页码、标题、来源说明和「开始关卡」目标。
- 内置关卡和本地关卡均可直接开始。

### 创建状态

- 点击「拍照创建新关卡」时沿用现有首次引导判断。
- 第一次创建先打开绘画引导；完成或跳过后打开相机。
- 已看过引导的用户直接打开相机。
- 点击「怎么画？」只打开引导，关闭后仍停留在关卡选择页。

### 生成状态

- 上传、轮询和下载期间锁定关卡列表、创建按钮、返回按钮、重新生成按钮和开始按钮，避免重复提交或切换目标。
- 状态区域展示现有服务返回的阶段文案，不虚构百分比。
- 生成成功后刷新列表，选中新关卡，更新预览并恢复交互。

### 重新生成状态

- 正常状态隐藏「重新生成」。
- 生成失败或本地存在未完成任务时显示「重新生成」。
- 点击后使用已暂存的同一张照片强制创建新任务。
- 用户需要更换照片时点击「拍照创建新关卡」，不通过「重新生成」打开相机。
- 不再提供单独的「继续生成」入口，也不继续轮询旧任务。

## 首页流程

首页只保留一个游戏入口：

```text
首页「开始游戏」
  → 关卡选择页
  ├── 选择已有内容 → 开始关卡
  └── 拍照创建新关卡 → 绘画引导或相机 → 生成 → 开始关卡
```

首页加载完成后隐藏原「拍照生成关卡」按钮，同时保留现有首页背景和其他装饰布局。首页不再保留第二条关卡选择入口。

## 异常与降级

- 本地关卡文件或预览图损坏：保留当前页面，状态区显示错误，不进入游戏。
- 内置关卡资源缺失：取消默认选中，禁用「开始关卡」，状态区显示可恢复错误。
- 上传、轮询或下载失败：解除繁忙状态，保留暂存照片，并显示「重新生成」。
- 绘画引导 Prefab 缺失：创建流程继续打开相机；主动帮助入口显示轻量错误。
- 相机不可用或权限失败：沿用现有相机错误提示，不切换页面。
- 运行时缩略图缺失：条目保留纸张、标题和来源说明，不因图片缺失而隐藏关卡。
- 任意分辨率下，返回、帮助、创建、重新生成和开始按钮不得移出安全区或互相遮挡。

## 测试与验收

### EditMode 测试

- Prefab 包含规定的静态节点、`Level Item Template` 和 `C1LevelSelection`。
- 空本地库仍显示并默认选中内置「第 1 页」。
- 本地关卡按顺序出现在内置关卡之后，点击后更新页码和选中状态。
- 正常状态隐藏「重新生成」；失败或存在未完成任务时显示。
- 点击「重新生成」使用暂存照片创建新任务，不继续旧任务，也不打开相机。
- 生成中所有关键交互均被锁定，成功或失败后恢复。
- 首次创建、已看过引导、主动帮助三条流程保持现有行为。
- 首页只有「开始游戏」能够进入关卡选择页，原拍照入口保持隐藏。
- 损坏本地资源不会触发场景切换，并显示错误信息。

### 视觉验收

- 在 `1920×1080`、近方形和 `2560×1080` 下渲染截图。
- 页面背景、标题、手账、纸片、装饰、按钮和字体与角色选择页属于同一套视觉语言。
- 左侧列表可滚动，至少容纳 10 个本地关卡，末尾创建入口仍可到达。
- 关卡预览保持原始宽高比，不拉伸、不裁掉关键内容。
- 选中态、禁用态、失败态和生成中状态均能一眼区分。
- 页面不出现测试样式的纯色矩形按钮、默认 Unity 字体或临时文案。

## 非目标

- 不新增关卡重命名、删除、收藏或排序功能。
- 不修改服务器关卡生成接口、轮询协议或识别算法。
- 不修改相机取景框、绘画引导内容或本地关卡文件格式。
- 不新增服务端任务取消或删除能力。
- 不重做首页、角色选择页和游戏 HUD 的整体视觉。
