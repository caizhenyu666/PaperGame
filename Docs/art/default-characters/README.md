# 默认角色动画资源

以用户提供的独眼小绿和披风小鸡设定图为身份参考，使用内置 imagegen 生成动作母图，再由 `Tools/pack_default_characters.py` 统一切帧、去除独立透明边缘杂点并导出 PNG。母图仅存于本目录的 source 中，不进入运行时 Resources。

最终规格：单帧 256×256；run、jump、idle 分别为独立的 2048×256 横排图集，各 8 帧。待机由 4 个源姿态按保持帧序列组成。两个角色使用相同画布、固定缩放和统一脚底锚点，禁止逐帧按包围盒缩放。缩略图及 UI 静态动作图均为 256×256。

Unity 导入：PPU 100，脚底 pivot 为 (128,26) 像素，透明 PNG，无纹理压缩，无 mipmap，Bilinear。人物静止有效高度约 190 像素；游戏内显示高度统一为 1.6 世界单位，不以整幅透明画布测量默认角色身高。

游戏主体碰撞体统一为 1.1×1.6 世界单位，偏移为零，视觉脚底置于 Player 原点下方 0.8。默认与远端角色通过 `C1CharacterSizing` 共用尺寸配置，切换动作不重新计算碰撞体。宽度针对主体设置，不覆盖每一帧向外摆动的手臂和披风；不修改 UI 预览尺寸或原 PNG 分辨率。

目录：`Assets/Resources/C1Character/Defaults/green`、`chick`。UI 兼容资源保留 `Assets/Resources/C1CharacterUI` 原有名称与 GUID，仅替换内容；运行时预览与游戏加载新图集。

服务器规格核对：本机缓存的三套角色单帧为 122×224、198×296、237×118；run 为 10 帧，jump 为 7 帧。服务端按内容联合边界计算尺寸，没有固定 512 分辨率。默认角色改用统一 256 画布，不修改远端角色协议和切帧逻辑。

## 生成提示词

两次 imagegen 分别引用对应角色设定图，要求：保持原角色外形、颜色和线条；完整身体；透明背景；4 列 5 行，共 20 个姿态；第一行四个正面待机姿态，第二和第三行八个朝右跑步循环姿态，第四和第五行八个跳跃阶段（蓄力、起跳、上升、收腿、顶点、下降、落地、恢复）；固定相机、人物比例和注册点；没有文字、网格、背景、地面或特效。小鸡保留红披风和蝴蝶结，披风在跑步时向后摆动；小绿保持独眼与深绿色四肢。母图生成尺寸为 1122×1402，最终仅使用标准化导出资源，不将母图当作动作图集直接导入。
