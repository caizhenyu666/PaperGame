# 正式主角界面

布局基准为横屏 1920×1080。首页现有 Canvas 已采用该基准，本次不重建或覆盖首页预制体。

## 使用

运行首页，点击“创建主角”即可打开正式界面。预制体位于 `Assets/Resources/C1UI/PaperGameCharacterSelection.prefab`，图片位于 `Assets/Resources/C1CharacterUI`。所有按钮、标题、背景、角色预览、选中框和星标是独立对象。

编辑器菜单 `PaperGame > UI > Generate Character Selection` 可重新生成角色界面；这会覆盖该角色预制体中的手动布局调整，不会覆盖首页。动态角色列表由控制器填充，预制体中的两个默认卡片用于编辑器预览。

## 交互

- 默认角色：独眼小绿（兼容旧 `default` ID）、披风小鸡（`default-chick`）。
- 点击卡片只切换浏览角色；黄色框表示正在浏览，黄色星标表示已保存使用的角色。
- “使用这个主角”保存到现有角色库并返回首页，关卡启动时应用保存的角色。
- “回到首页”不提交当前浏览的角色。
- 跑跳卡片切换中间的动作预览；自定义角色使用服务器提供的动画帧。
- 两个拍照入口共用现有拍照、上传、轮询、下载及失败重试流程。忙碌期间禁止重复请求；错误或未完成任务时显示重试入口。

当前提供的是静态角色切图，不是完整动画图集。绿色角色有站立、跑、跳三个姿态；小鸡使用站立图及位移预览。角色从用户参考效果图提取，不使用工程原有的像素小男孩。以后可用正式透明角色图/动画图集替换这些切图。

## 验证

Unity 2022.3.62f1 在独立临时工程中生成预制体并渲染 1920×1080 预览，未打断用户当前 Unity 工程。

新增 5 个测试覆盖：独立预制体结构、两个默认 ID 保存、切换预览后确认保存、返回不保存。已验证测试从原实现失败到新实现通过。

全量 EditMode：111 项，108 通过、3 失败。去除本次角色应用改动后，这三个测试仍同样失败：

- `DefaultBaseUrl_UsesProjectWebGlSettings`：已有测试期待 HTTP 地址，工程设置已经使用 HTTPS :8443。
- `Build_MockApiLevelCreatesGeometryAlignedToProvidedImage`：已有出生点预期与当前关卡坐标不符。
- `GenerateHomePrefab_CreatesIndependentOverlayImages`：已有首页测试按旧节点结构查找对象。

没有为消除这三个无关失败去更改用户的首页、接口配置或关卡坐标。拍照服务使用已有 HTTP 测试验证上传/轮询/下载流程；未向真实服务上传照片或产生生成费用。
